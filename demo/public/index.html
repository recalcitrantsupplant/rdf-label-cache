Labels for your RDF, served from a CDN.

Every RDF app resolves IRI → label endlessly - for predicates, classes and entities. Do it once from a globally edge-cached CDN: rdfs:label, skos:prefLabel, schema:name and your own IRIs, resolved at the edge and never from your triplestore.

Deploy your own

Deploy your own RDF Label Cache. It ships empty; you populate R2 once with your own IRIs and any other ontologies you reference (Schema.org, DCAT, …).

1

Clone & install

git clone …/rdf-label-cache && pnpm install
2

Dump annotation properties

One SPARQL CONSTRUCT → labels + descriptions for every IRI your data mentions.

3

Set up Cloudflare & get credentials

Sign up or log in, create the R2 bucket, deploy the Worker, and make an R2 API token.

4

Configuration

Put your SEED_BASE (the deployed Worker URL) and R2 keys in .env.

5

Generate & upload

node scripts/ingest.mjs --input data.ttl && node scripts/upload-seed.mjs
6

Consume from your app

Plain HTTP GETs, fired concurrently over HTTP/2/3.
