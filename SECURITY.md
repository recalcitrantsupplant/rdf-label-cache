# Security Policy

## Supported versions

Security fixes are applied to the latest `main` branch and the most recent
release only. Older releases are unsupported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
to the repository maintainer through GitHub's private vulnerability-reporting
feature, or contact the maintainer listed on the repository profile. Include a
minimal reproduction, impact, and any suggested mitigation.

You should receive an acknowledgement within seven days. Please do not publish
details until a fix or mitigation has been agreed.
