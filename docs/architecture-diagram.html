RDF Label Resolver

A globally distributed, low-latency service for resolving human-readable labels for RDF IRIs. One Worker, one R2 bucket, a platform-managed tiered cache in front. No databases, no auth, no middleware.

1 · Architecture overview

Requests flow top-to-bottom. Workers Cache sits in front of the Worker — cache hits are served without ever invoking it.

Cache layer (hits skip the Worker) Fast return path — no CPU billed Blob store

2 · Request lifecycle

The cold path only — a warm cache short-circuits at step 2.
